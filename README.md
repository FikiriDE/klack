# Knobel Klack

Nachbau des Reaktions- und Knobelspiels nach der Original-Bedienungsanleitung, im Browser spielbar.

- Grundstellung „8888“ nach dem Löschen mit 1+2+3
- Reaktionsspiel (Taste 6, Stufe 1 oder 2)
- Knobelspiel (Taste 2, Stufe 1 bis 3), Pause mit 3+4+5
- Uhr mit Wecker (Taste 1)

Starten: `index.html` im Browser öffnen. Bedienung per Maus/Touch oder Tasten 1–6. Eine Kurzanleitung steht unter dem Gerät.
