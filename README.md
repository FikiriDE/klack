# Blitzdreieck

Reaktions- und Knobelspiel auf einem Dreieck mit sechs Tasten, im Browser spielbar. Vorbild ist ein Elektronikspiel aus den 1980ern.

- Spiel und Stufe im Auswahlfeld unter dem Blitzdreieck wählen, dann Start
- Reaktionsspiel (Stufe 1 oder 2)
- Knobelspiel (Stufe 1 bis 3) mit Pause

Starten: `index.html` im Browser öffnen. Bedienung per Maus/Touch oder Tasten 1–6. Die Spielanleitung steht auf der Seite unter dem Blitzdreieck.
